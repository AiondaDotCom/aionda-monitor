# Aionda Monitor identity

Product lockup created for Aionda Monitor on 2026-09-28 using the existing Aionda
brand assets provided by the project owner. The cyan/turquoise Aionda symbol and
wordmark are paired with a Monitor label.

Reference: https://agentboard.aionda.com/aionda_logo.png
Higher-resolution light/dark brand variants come from Aionda's website assets.

- aionda-monitor-logo.svg: product lockup on a dark background
- aionda-monitor-icon.svg: compact monitoring icon
- ../../html/images/logos/aionda-monitor.svg: light-theme product lockup
- ../../html/images/logos/aionda-monitor-dark.svg: dark-theme product lockup

The lockups embed the original raster Aionda wordmark to preserve its typography.
Aionda brand and trademark rights remain with their respective owner.
No Nagios logo is used for the product identity.
