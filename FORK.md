# Project origin

Aionda Monitor was established as an independent project by Aionda on 2026-09-28.
It is derived from Nagios Core 4.5.14, with the upstream Git history retained.

Upstream: https://github.com/NagiosEnterprises/nagioscore
Project: https://github.com/AiondaDotCom/aionda-monitor

Original Nagios Core copyrights, LICENSE, THANKS, and file-level notices are retained.
Aionda's modifications include the web interface redesign, form authentication,
MCP integration, and project branding. Consult Git history for individual changes.

## Initial independent-project changes (2026-09-28)

- Introduce the Aionda Monitor name, Aionda product lockup and monitoring icon.
- Identify the independent fork in the README and web interface.
- Rebrand primary UI, daemon banner, CGI status header and MCP server identity.
- Remove the home-page promotion and disable page tours in the sample configuration.
- Retain configuration, executable and path compatibility for existing installations.

Historical documentation, filenames and third-party assets may still refer to Nagios.
These references do not make Aionda Monitor an official Nagios product.
